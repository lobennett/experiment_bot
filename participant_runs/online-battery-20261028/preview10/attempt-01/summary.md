# Preview 10: partial direct-browser baseline

The synthetic participant reached practice but could not maintain observation–response correspondence within the live trial timing. The session was stopped, without restarting or changing task state. No main-test or task completion is claimed.

Instructions mapped red ink to comma, blue ink to period, and green ink to slash; word identity was to be ignored ([instructions](evidence/07_begin.txt), [screenshot](evidence/instructions.png)). Practice included feedback and a reminder; the instructions said these would be removed during the test. The introductory estimate was seven minutes.

A [screenshot](evidence/first_trial.png) showed blue in green ink. The model selected slash, but the task advanced before key delivery. [Correct feedback](evidence/after_response.png) followed for a later response opportunity. The [practice feedback](evidence/16_feedback.txt) subsequently reported omissions and low accuracy and announced an automatic repeat. The same session continued automatically while evidence was being archived; it was then stopped through the isolated browser tool.

The [native export](data/experiment_data.json) contains 44 platform rows, including 9 practice response trials: 1 response recorded as correct and 8 omissions. The one response has native RT 534 ms. This is not evidence of a 534 ms observation–inference–action cycle: it landed on a later trial than the screenshot. The platform records a 1,000 ms stimulus display and 1,500 ms response trial. These data were obtained after the decision to end participation through the documented read-only [jsPsych export API](https://www.jspsych.org/6.3/core_library/jspsych-data/#jspsychdataget). The JSON string was decoded from the tool transport without reformatting its bytes. The first truncated export capture is retained alongside the full capture.

The sandboxed browser bridge initially timed out. An escalated isolated launch succeeded. One stale navigation reference was refreshed before retrying; no response was duplicated. Subsequent calls typically took roughly 0.2–0.9 seconds, in addition to model inference and screenshot interpretation. Screenshots preserved ink color that accessibility text omitted.

The ontology records the mappings, instructional phase distinction, observed feedback, and post-session native timing. Main-test structure and terminal completion remain unknown. This exploratory baseline is separate from the frozen participant-program study. It demonstrates a real mechanical timing boundary of the direct-browser skill, not human behavioral validity. A future explicitly labeled resident execution mode would need to use only current visible stimuli and preserve first-attempt data; changing clocks, reading hidden answers, or selecting behavioral results would not resolve this evidence gap.
